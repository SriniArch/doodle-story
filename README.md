# Doodle Story Studio

Build DoodleDiary, a web app that turns journal entries into animated stick-figure stories. Include a clean, hand-drawn doodle aesthetic with a journal input area and mood selector (Funny, Emotional, Motivational, Calm). Implement a modular storyboard generator that creates 4–6 scene JSON storyboards from the text, rendered with simple browser-based SVG/CSS animated stick figures, props (clock, bed, coffee, laptop, car, etc.), captions, and playback controls (Play, Pause, Replay, Create Another Story). Include mock generator logic out of the box so it runs completely in the browser without requiring an API key.
